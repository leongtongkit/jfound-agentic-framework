A working model of *how the user decides*, distinct from static facts in
`user-profile`. Surfaced in the self-drive pre-flight manifest so the user can
correct a wrong read of themselves *before* the agent acts on it. That
correction loop is what makes this converge on the real person instead of
drifting into a flattering fiction.

**Rules for this file:** every pattern cites the observation it came from. No
evidence → mark `(provisional)`. A contradiction *revises* the entry — don't
just append a conflicting one. This is a falsifiable model, not a portrait.

# Memory inbox — unprocessed session deltas

Auto-extracted candidates written by the session-journal hook at session end.

**This is staging, NOT curated memory. Never read as fact.**

At the next session's pre-flight (see `framework/AGENTS.md` → Self-driven goals,
step 1), the primary agent drains this file: review each block, merge the real
signal into the right curated memory file (and the index), discard the noise,
then delete the processed block. A cheap model proposes here; the capable model
disposes. That review step is the quality gate that keeps memory from silting
up into noise.
